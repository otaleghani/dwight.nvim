# dwight.nvim

> _"I'm not superstitious, but I am a little stitious."_
> **An AI-powered development companion for Neovim.**

![Neovim](https://img.shields.io/badge/neovim-0.10+-57A143?style=flat-square&logo=neovim)
![Lua](https://img.shields.io/badge/lua-5.1-2C2D72?style=flat-square&logo=lua)
![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)

**Dwight** is a Neovim plugin that orchestrates AI agents to plan, build, test, and ship code — all without leaving your editor. It scopes work through feature pragmas, delegates multi-step tasks to autonomous agents with verification gates, and learns from every session.

Take a look at the [documentation](https://dwight.talesign.com/) to get started.
